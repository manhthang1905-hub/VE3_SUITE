# FlowKit Integration Guide for VE3_SUITE

## What is FlowKit?
FlowKit is a Chrome Extension + Python Agent system that generates images/videos via Google Flow API (Veo).
The Chrome Extension captures auth tokens, solves reCAPTCHA, and proxies API calls.
The Python Agent (FastAPI) manages requests via WebSocket with the extension.

## What's NOT Working Yet (Bugs to Fix)

### BUG 1: Project ID (CRITICAL)
**Problem**: VE3 sends fake `project_id` in API requests. The adapter's `_ensure_project()` tries to create a real Flow project via tRPC but response parsing fails → falls back to random UUID → Google rejects API calls.

**Root cause**: `create_project()` tRPC response structure not parsed correctly in `ve3_compat.py` lines 59-68.

**Fix needed**: Add `extract_project_id` method to extension that reads the project ID from the open Flow tab URL (e.g., `https://labs.google/fx/tools/flow/project/REAL-UUID`). This is the most reliable approach.

**Files to modify**:
- `extension/background.js` — add handler for `extract_project_id` message type
- `agent/services/flow_client.py` — add `extract_project_id()` method
- `agent/api/ve3_compat.py` — modify `_ensure_project()` to use browser extraction first

### BUG 2: Chrome Portable Launcher
**Problem**: `GoogleChromePortable.exe` wrapper does NOT pass `--load-extension` flag to real Chrome binary.

**Fix**: Use `chrome.exe` directly:
```
D:\VE3_SUITE\GoogleChromePortable - Copy (N)\App\Chrome-bin\chrome.exe
  --user-data-dir="D:\VE3_SUITE\GoogleChromePortable - Copy (N)\Data\profile"
  --load-extension="D:\VE3_SUITE\flowkit_extensions\ext_810N"
  --no-first-run
  https://labs.google/fx/tools/flow
```
**File to modify**: `flowkit_launcher.py` `start_chrome()` function

### BUG 3: Port TIME_WAIT on Windows
**Problem**: After killing agent, port stays in TIME_WAIT ~60s. New agent can't bind.

**Fix needed**: Add port availability check with retry before starting. Partially implemented with SO_REUSEADDR but WebSocket server binding still fails sometimes.

**File to modify**: `agent/main.py` `run_ws_server()` — add wait-for-port loop

### BUG 4: reCAPTCHA Evaluation Failed
**Problem**: Image generation returns "reCAPTCHA evaluation failed" from Google.

**Likely cause**: Combination of BUG 1 (wrong project_id in URL) + possibly account flagging.

**Fix**: Fixing BUG 1 should resolve this. The upload endpoint works fine (no captcha needed), proving the extension connection works.

## Architecture

```
VE3 Worker
  ├── mode: "server"    → POST to VE3 server pool (existing)
  ├── mode: "flowkit"   → POST to FlowKit instances only
  └── mode: "combined"  → FlowKit first → server fallback

Each FlowKit Instance:
  Chrome Copy (N) ←→ Extension (ext_810N) ←WebSocket(922N)→ FlowKit Agent (port 810N)
                                           ←HTTP callback→

VE3 Worker → GoogleFlowAPI(local_server_url="http://127.0.0.1:810N")
  → POST /api/fix/create-image-veo3  (VE3 format)
  → FlowKit adapter translates → Extension → Google Flow API
  → Poll /api/fix/task-status → result
  → Download image/video → Save to img/vid/ → Update Excel
```

## How to Run (Once Bugs Fixed)

### Step 1: Generate extensions (already done)
```bash
cd D:\VE3_SUITE\tools\flowkit
python setup_extensions.py --chrome-dir "D:\VE3_SUITE" --base-port 8100
```

### Step 2: Install extension in each Chrome
For each Chrome Copy (N), either:
- **Manual**: Open Chrome → chrome://extensions → Developer mode → Load unpacked → `D:\VE3_SUITE\flowkit_extensions\ext_810N`
- **Auto**: Use `chrome.exe --load-extension=...` (see BUG 2 fix)

### Step 3: Start FlowKit agents
```bash
# Single instance
cd D:\VE3_SUITE\tools\flowkit
API_PORT=8100 WS_PORT=9222 python -m agent.main

# Multi-instance via launcher
python flowkit_launcher.py --chrome-dir "D:\VE3_SUITE" --base-port 8100
```

### Step 4: Configure VE3
Add to project config or settings:
```yaml
generation_backend: "flowkit"  # or "combined"
flowkit_server_list:
  - url: "http://127.0.0.1:8100"
    name: "flowkit-1"
    enabled: true
  - url: "http://127.0.0.1:8101"
    name: "flowkit-2"
    enabled: true
```
