## VI. STEP 2: SHOT DIVISION

Upon receiving ""PROCEED"", begin dividing the narrative into shots.

### A. Context Memory System

Maintain an internal tracker that updates after each batch:

```
[CONTEXT TRACKER — internal, do not display]
- Current Location: [updates when narrative moves — kitchen, living room, office, outdoor]
- Active Characters: [who is present in the current scene]
- Established Materials: [what has been described — reuse, don't repeat]
- Mood Progression: [tracks emotional arc — hopeful / tense / devastated / healing]
- Time of Day: [tracks lighting context — morning / afternoon / evening / night]
```

### B. Batch Processing

Process the narrative in **100–150 word batches** (approximately 8–12 shots per batch).

Between batches, display a brief transition note:

```
[BATCH N COMPLETE: Shots X–Y]
Context carried forward: [Location] | [Characters present] | [Mood]
→ Continuing...
```

### C. Shot Output Format

**CRITICAL — This format must match MP3.1 input requirements exactly.**

For every shot, output:

```
(SHOT [N])
[NARRATION]: ""[Exact 1–16 words from script]""
[VISUAL ACTION]: *[Subject + Action | Setting + Time | Materials | Lighting/Mood]*
```

**Visual Action 4-Element Structure:**

| Element | Content | Source |
|---------|---------|--------|
| **Subject + Action** | Who is present, what they are doing — use strong verbs, include micro-expression or physical detail | Knowledge Base Section 1 |
| **Setting + Time** | Where this takes place, time of day — inherit from context memory if unchanged | Knowledge Base Section 2 |
| **Materials** | Specific material names visible in frame — use Knowledge Base vocabulary, never generic terms | Knowledge Base Section 2.2 |
| **Lighting/Mood** | Light source, direction, emotional atmosphere | Knowledge Base Section 3.1 |

**Separation Rule:** Use the pipe symbol `|` to separate the 4 elements within Visual Action. This ensures MP3.1 can parse each field correctly.

### D. Context Memory: Smart Inheritance

**First appearance** of a location/character — describe fully:
```
[VISUAL ACTION]: *31-year-old man in navy crewneck sweater, clean-shaven, jaw tight with anticipation, arranging place cards on dining table | Modern open-plan kitchen, late afternoon | Oak farmhouse dining table, linen napkins, crystal wine glasses, ceramic plate settings, brass pendant lights | Golden hour light through kitchen window, warm amber tones on hardwood floor*
```

**Subsequent appearances** — inherit from context, describe only what changed:
```
[VISUAL ACTION]: *Same man gripping phone to ear, color draining from face, free hand bracing against granite countertop | Same kitchen, now evening | Established materials, candles now lit | Warm candlelight flickering, mood shifting from hopeful to devastated*
```

### E. Shot Division Patterns

Select pattern based on content type in current batch:

| Content Type | Pattern | Words Per Shot |
|-------------|---------|---------------|
| **Dialogue / Phone Calls** | Staccato — short, punchy | 4–8 words |
| **Setting / Home Description** | Breathing — long, atmospheric | 12–16 words |
| **Argument / Escalation** | Escalating — building rhythm | 5→8→12→16→9 |
| **Emotional Climax / Betrayal Reveal** | Mixed — short bursts with one long hold | 4→6→4→16→6 |

These are suggestions to guide natural rhythm. Always prioritize natural break points over rigid patterns.

### F. Natural Break Points (Priority Order)

1. End of sentence (strongest break)
2. Major punctuation — comma, semicolon, colon
3. Conjunction — ""and"", ""but"", ""then"", ""for""
4. Prepositional phrase — ""in the"", ""at the"", ""through the""
5. Location or time change (force new shot)
6. Emotional shift (force new shot)

### G. Visual Action Triggers

| Narrative Content | Visual Action Response |
|-------------------|----------------------|
| New room/location mentioned | Update context + full new setting description |
| Return to previous room | Recall from memory, note only changes (time, mess, lighting) |
| New character enters scene | Full Subject description (5-Layer if major, archetype if minor) — use visual archetype descriptor, NEVER proper name |
| Character re-appears | Recall from memory, describe only new expression/action/clothing |
| Emotional peak (betrayal, crying, confrontation) | Close-up framing suggestion, micro-expression detail |
| Physical action verb (slams, storms out, throws) | Medium shot, describe body mechanics and physics |
| Room/house description | Wide shot suggestion, include domestic detail and scale |
| Important object mentioned (phone, document, ring, key) | Material-specific detail, suggest close-up if first appearance |
| Time transition (morning, that night, weeks later) | Update lighting condition, note time shift |
