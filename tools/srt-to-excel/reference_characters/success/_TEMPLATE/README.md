# 🌱 VE3 Self-Development Channel — Setup Guide for AI Assistants

> **You are configuring a new success ("phat trien ban than" / self-development) YouTube channel for the VE3 automated video pipeline.**
> This document contains everything you need to create a fully functional channel.

---

## 📌 What This System Does

This pipeline generates **educational self-development videos** automatically:
1. Takes an SRT subtitle file (in any language)
2. AI analyzes the self-development content (habits, mindset, discipline, goals, growth)
3. AI generates image prompts + video prompts for each scene
4. Images are generated by AI (Flux/DALL-E)
5. Videos are assembled with narration + images + animations

**Each channel targets a SPECIFIC country/language audience.** The `style.yaml` you create here controls:
- The visual art style (how the character and scenes look)
- The cultural context (what objects, settings, metaphors feel familiar to that audience)
- The motivational expression style (how the culture shows effort, progress, struggle, growth)

## 🚀 Step-by-Step: Create a New Channel

### Step 1: Create the folder
```
reference_characters/success/MT1-T{N}/
```

### Step 2: Add `nv1.png`
This is the **character reference image**. The user will provide it.
- It's a 2D illustrated character (not photorealistic)
- Each channel has a unique character design (usually a different outfit)
- ALL scene images will match this character's style

### Step 3: Create `style.yaml`
Copy `style_template.yaml` and fill in ALL fields. See detailed field guide below.

### Step 4: Validate
```bash
python validate_channel.py MT1-T{N}
```

### Step 5: Done!
The pipeline auto-discovers new channels from `style.yaml`. **No Python code changes needed.**

## 📋 Field-by-Field Guide

### CRITICAL: How to write `image_style`

**This is the most important field.** Look at `nv1.png` and describe EXACTLY what you see:

| What to describe | Example |
|-----------------|----------------------|
| Body shape/size | "short stocky body" |
| Head shape | "large round white head" |
| Face features | "small black dot eyes and a tiny simple mouth" |
| Hair | "short spiky dark-outlined hair" |
| Clothing top | "warm terracotta cable-knit sweater" |
| Clothing bottom | "khaki tan pants" |
| Shoes | "white low-top sneakers" |
| Line style | "even charcoal-black outline with slight line-weight variation" |
| Background | "warm cream paper-tinted background" |
| Shadow/wash | "soft gray graphite shadows" |
| Mood | "calm encouraging growth-minded mood" |
| Negatives | "no real humans, no photorealism, no 3D, no readable text, no watermark" |

**Combine all into one paragraph.** This exact description gets injected into EVERY image prompt.

### Other Visual Fields

| Field | What it does | How to write it |
|-------|-------------|----------------|
| `style_name` | Unique ID (snake_case) | Combine key visual traits: `warm_terracotta_knit_round_head` |
| `video_style` | Animation rules | "Same [style] style, gentle motion, [clothing] preserved, [background]" |
| `thumbnail_style` | YouTube thumbnail | "[style] thumbnail, [key feature], one symbolic growth prop, clickable composition" |
| `scene_plan_style` | Scene planning language | "[style] language, [character desc], [background], symbolic props, body posture" |
| `palette` | 5-7 key colors | Extract from nv1.png: "warm terracotta, khaki tan, cream paper, charcoal outline" |
| `negative_prompt` | What to NEVER generate | Always include: "no real humans, no photorealism, no 3D, no readable text, no watermark" |

### Character Locking Fields

These ensure the AI generates the SAME character every time:

| Field | Purpose | Length |
|-------|---------|--------|
| `reference_lock` | Strict instruction to match nv1.png | 100+ chars |
| `technical_suffix` | Consistency rules for all elements | 80+ chars |
| `engagement_rules` | Composition guidelines | 60+ chars |
| `default_character_prompt` | Standalone generation prompt | 100+ chars |
| `default_character_lock` | Short inline reference | 50+ chars |

### Cultural Fields (THE DIFFERENTIATOR)

These are what make each channel feel authentic to its audience:

#### `audience_language`
Just the language name in English: `"Japanese"`, `"Korean"`, `"Spanish"`, `"German"`, etc.
**The pipeline auto-detects this — no code change needed.**

#### `audience_culture_note`
A rich paragraph describing the target audience's visual world:
- Age range (typically 18-40)
- 5-8 specific daily life settings (apartments, desks, cafes, parks, streets)
- 3-5 local self-development / growth concepts (local terms for discipline, perseverance, drive)
- 5-8 everyday props that feel familiar
- Motivational expression preferences
- What to avoid

**Example (Korean 🇰🇷):**
> Design for Korean self-development viewers aged 18-40 focused on self-discipline, focus and self-improvement. Use settings from modern Korean daily life: small studio (one-room) desks, study room (doksoshil) corners, cafes with iced americano, morning apartment-complex paths, tidy bedrooms. Emphasize kkujunhi (steadily and consistently), noryeok (effort), jagi gyebal (self-development), seongsil (sincere diligence). Props: iced americano cup, habit planner, desk lamp, running shoes. Korean audiences respond to focused, modern, motivating visuals — show effort through tidy study spaces and visible habit streaks.

#### `cultural_props`
Comma-separated list of **8-12 specific objects** that replace generic Western props.

| Generic (BAD) | Culturally specific (GOOD) |
|--------------|--------------------------|
| coffee mug | yunomi tea cup 🇯🇵 |
| coffee mug | iced Americano cup 🇰🇷 |
| coffee mug | espresso tazzina 🇮🇹 |
| coffee mug | tulip-shaped tea glass 🇹🇷 |
| bench | train-station bench 🇯🇵 |
| bench | Han River park bench 🇰🇷 |
| bench | stone plaza bench 🇪🇸 |

#### `cultural_metaphors`
Pipe-separated concept:visual mappings. Include the **10 core self-development concepts**.

Format:
```
concept: detailed visual scene with nv1 | concept: scene | concept: scene
```

**Required concepts** (map each one):
- `procrastination` — putting tasks off / distraction
- `discipline` — steady consistent action
- `small_steps` — incremental progress
- `goal` — a clear target / vision
- `comfort_zone` — stepping out of safety into challenge
- `focus` — removing distraction, single-tasking
- `growth` — visible personal development
- `confidence` — self-belief, standing tall
- `resilience` — getting back up after failure
- `time_management` — organizing the day

**Each metaphor must:**
- Include `nv1` (the character)
- Use a cultural prop from the `cultural_props` list
- Be a concrete visual scene, not abstract
- Feel familiar to someone from that culture

#### `cultural_emotion_style`
How this culture expresses motivation and effort visually:
- What gesture style? (restrained vs expressive)
- What settings feel like real effort? (quiet morning desk vs busy gym)
- What visual rhythm? (steady stillness vs movement)
- What cultural concept drives growth?

## 🔍 How the Pipeline Uses Each Field

```
SRT File (any language)
    ↓
Step 1: Content Analysis
    Uses: audience_language, audience_culture_note, cultural_props, cultural_metaphors
    → AI understands the cultural context from the start
    ↓
Step 2: Segmentation
    Uses: audience_language, cultural_props
    → Segments reference culturally relevant objects
    ↓
Step 3-4: Scene Splitting & Spec
    Uses: cultural_metaphors (for non-Latin SRT concept extraction)
    → If SRT is Japanese/Korean/etc., uses cultural_metaphors as fallback
    ↓
Step 4.5: Scene Planning
    Uses: ALL cultural fields injected into planning prompt
    → AI director plans culturally grounded scenes
    ↓
Step 5/7: Prompt Generation
    System prompt gets: PREFERRED CULTURAL PROPS + CULTURAL METAPHORS + EMOTION STYLE
    User prompt gets: PREFERRED PROPS + CULTURAL METAPHORS
    → AI writes image/video prompts using cultural vocabulary
    ↓
Fallback (if AI fails):
    Uses: cultural_props for default subject/action/movement
    → Even fallback prompts are culturally grounded
    ↓
QA Review → Fix:
    Uses: ALL style fields for consistency checking
    → Repairs maintain cultural authenticity
```

## ⚠️ Common Mistakes

1. **Copy-pasting from another channel** without changing cultural content
   → Validate catches duplicate `style_name` and `audience_language`

2. **Generic image_style** that doesn't match nv1.png
   → Look at the image CAREFULLY. Describe exact clothing, colors, proportions.

3. **Too few cultural_props** (less than 5)
   → Need variety: furniture, food/drink, accessories, outdoor objects, habit objects

4. **Abstract cultural_metaphors** without nv1
   → BAD: "discipline: a checkmark"
   → GOOD: "discipline: nv1 marks one box in a habit notebook, a steady row already filled"

5. **Missing cultural_emotion_style**
   → This tells the AI HOW to show effort and progress, not just WHAT to show

6. **Text in image_style description**
   → ALWAYS end with "no readable text, no watermark"

## 💡 Pro Tips for AI Assistants

1. **Always view nv1.png first** before writing any style fields
2. **Research the target culture** — what does daily life look like? What objects are on a desk where someone builds new habits?
3. **Think about the viewer**: a 25-year-old in Seoul watching self-development content at midnight. What room are they in? What's on their desk?
4. **cultural_metaphors should tell micro-stories**: not "nv1 is disciplined" but "nv1 marks one box in a habit notebook, a steady column already filled"
5. **Use the existing channels as quality reference** — read MT1-T7 (Japanese) and MT1-T8 (Korean) for the gold standard
6. **All prompts the pipeline generates are in ENGLISH** — cultural_props can be in local language (like Spanish: "taza de cafe") but the AI will translate when generating image prompts
